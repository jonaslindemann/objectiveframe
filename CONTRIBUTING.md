# Contributing to ObjectiveFrame

Thanks for helping improve ObjectiveFrame. Contributions can be code, examples, documentation, bug reports, teaching material, or validation cases.

## Good First Contributions

- Add or improve example `.df3` models.
- Add screenshots or short GIFs for documentation.
- Improve quick start and student exercises.
- Report unclear UI workflows.
- Add small ChaiScript plugins or examples.
- Improve build instructions for a specific platform.

## Reporting Bugs

Use the bug report template and include:

- ObjectiveFrame version or commit.
- Operating system.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Screenshot, model file, or crash log if available.

## Suggesting Features

Use the feature request template and describe:

- The teaching, modelling, or analysis problem.
- The workflow you would like to improve.
- Any example files or screenshots that make the request clearer.

## Code Contributions

Before opening a pull request:

1. Keep changes focused.
2. Follow the existing C++ style.
3. Build the project locally.
4. Add or update documentation when behavior changes.
5. Include example models or screenshots for user-facing workflow changes.

## Documentation Contributions

The documentation lives under `docs/docs`. Useful additions include:

- Quick start improvements.
- Example walkthroughs.
- Student exercises.
- More screenshots.
- Short demo GIFs or video links.

## Example Contributions

When adding examples, include:

- A `.df3` model.
- A short description of what it demonstrates.
- A screenshot or thumbnail if possible.
- Notes about expected results or interesting modelling choices.
