# Security Policy

ObjectiveFrame is a desktop engineering and education application. Security reports are still welcome, especially for issues involving file parsing, scripting, plugins, or packaged releases.

## Supported Versions

The latest GitHub release and the current `master` branch are the primary supported versions.

## Reporting a Vulnerability

Please report security-sensitive issues privately to the project maintainer before opening a public issue.

Include:

- A short description of the problem.
- Steps to reproduce.
- Affected version or commit.
- Any example file needed to reproduce the issue.

## Scripting and Plugins

ObjectiveFrame supports scripted workflows. Only run scripts and plugins from sources you trust, especially when using AI-generated scripts or downloaded examples.
