# Cite ObjectiveFrame

If ObjectiveFrame supports teaching, research, or published work, please cite the software and, where relevant, the related academic publications.

## Software Citation

Use the repository citation metadata in `CITATION.cff`, or cite the software manually:

```bibtex
@software{objectiveframe,
  author = {Lindemann, Jonas},
  title = {ObjectiveFrame: Interactive real-time finite element analysis for structural mechanics education},
  url = {https://github.com/jonaslindemann/objectiveframe},
  year = {2026},
  note = {Open-source software. Version: see GitHub releases}
}
```

The software has no DOI yet. Until an archived release is published, cite the repository and the release version you used.

## Related Publications
