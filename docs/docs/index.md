# Welcome to the ObjectiveFrame website

ObjectiveFrame is a finite element beam analysis application developed at Structural Mechanics at Lund university. The application focused on how to make finite element analysis real-time explorable with direct feedback methods. I also implements a special eigen mode visulization method that allows users to explore the modal properties of their structures in real-time. The application is built using C++ and OpenGL, and it is designed to be extensible and customizable for different use cases.
